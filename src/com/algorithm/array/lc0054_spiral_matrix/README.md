# 螺旋矩阵 II

## 题目链接

[LeetCode 54. Spiral Matrix](https://leetcode.cn/problems/spiral-matrix/)  
[LeetCode 59. Spiral Matrix II](https://leetcode.cn/problems/spiral-matrix-ii/)

## 解题思路

按螺旋方向填充矩阵的思路：
1. 按圈处理矩阵，每圈分为四个方向（上、右、下、左）填充
2. 使用 `offset` 控制每圈边的长度，每圈结束后右边界收缩
3. 使用 `startX` 和 `startY` 记录每圈的起始位置
4. 若 n 为奇数，最后单独处理中间的元素

## 关键点分析

- **边界处理原则**：采用「左闭右开」原则，避免重复处理
- **圈数计算**：n 阶矩阵需要循环 `n / 2` 圈
- **变量设计**：
  - `startX, startY`：每圈起始位置
  - `offset`：控制每条边的遍历长度
  - `count`：用于填充数字
  - `loop`：当前圈数

## 时间复杂度与空间复杂度

- 时间复杂度：O(n²)，需要遍历矩阵中的每个元素
- 空间复杂度：O(n²)，需要使用结果矩阵

## 易错点

- 边界控制容易出错，要注意每条边的终止条件是 `n - offset` 而不是 `n - 1`
- 圈结束后要及时更新 `startX`、`startY`、`offset` 和 `loop`
- n 为奇数时容易忘记单独处理中间的元素

## 复盘或优化思路

这是一道经典的模拟题，主要考察边界条件处理能力。该实现是标准解法，若需要优化可考虑：
- 进一步简化变量，如用 `i, j` 直接表示当前坐标
- 添加更详细的边界注释
