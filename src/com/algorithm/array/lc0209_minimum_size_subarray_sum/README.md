# 长度最小的子数组

## 题目链接

[LeetCode 209. Minimum Size Subarray Sum](https://leetcode.cn/problems/minimum-size-subarray-sum/)

## 解题思路

这是一道典型的滑动窗口题目。使用滑动窗口（双指针）的思路：
1. 使用 `left` 和 `right` 两个指针表示窗口的左右边界
2. 不断扩展 `right` 指针，将元素加入窗口
3. 当窗口内的和 `sum >= target` 时，尝试收缩 `left` 指针以寻找更小的窗口
4. 记录满足条件的最小窗口长度

## 关键点分析

- **滑动窗口的设计**：
  - `left` 表示窗口左边界，`right` 表示窗口右边界
  - `sum` 表示当前窗口内元素的和
  - `result` 记录最小窗口长度，初始设为 `Integer.MAX_VALUE`

- **窗口调整策略**：
  - 外层循环移动 `right` 扩大窗口
  - 内层循环当 `sum >= target` 时移动 `left` 缩小窗口
  - 每次满足条件时更新最小长度

## 时间复杂度与空间复杂度

- 时间复杂度：O(n)，每个元素最多进出窗口一次
- 空间复杂度：O(1)，使用常数级别的额外空间

## 易错点

- 初始时 `result` 需要设为最大值，最后要判断是否为最大值来决定返回 0
- 不要忘记在缩小窗口时同时更新 `sum` 和移动 `left` 指针
- 窗口长度计算是 `right - left + 1`，容易漏掉 +1

## 复盘或优化思路

这道题是滑动窗口的经典模板。当前实现已经是最优解法，若需要优化可考虑：
- 添加更多边界情况的测试
- 对比前缀和 + 二分查找的解法
