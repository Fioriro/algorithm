# LC27. Remove Element

## 题目
- 题号：27
- 题目名称：Remove Element
- 链接：https://leetcode.com/problems/remove-element/

## 解题思路
- 使用双指针法，快慢指针从同一端开始遍历
- 快指针用于探索未处理的元素，慢指针用于标记新数组的下一个位置
- 当快指针遇到目标值时，只移动快指针；否则，将元素复制到慢指针位置并同时移动两个指针

## 关键点
- 原地修改数组，不需要额外空间
- 双指针技巧的应用

## 复杂度分析
- 时间复杂度：O(n)，其中 n 是数组的长度
- 空间复杂度：O(1)，只使用常数级别的额外空间

## 易错点
- 边界条件的处理，如数组为空或数组中所有元素都是目标值的情况

## 复盘/优化
- 该方法是最优解，已经达到了时间和空间复杂度的最优
- 可以考虑使用相向双指针法，但对于本题场景，同向双指针更简单易理解
