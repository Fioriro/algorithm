# 二分查找

## 题目链接

[LeetCode 704. Binary Search](https://leetcode.cn/problems/binary-search/)

## 解题思路

使用经典的二分查找算法，通过不断缩小搜索范围来定位目标值。算法的核心思想是：
1. 定义左右边界指针
2. 计算中间位置
3. 比较中间值与目标值的大小
4. 根据比较结果调整搜索范围
5. 重复直至找到目标值或搜索范围为空

## 关键点分析

- **搜索范围**：使用闭区间 `[left, right]` 以简化边界处理
- **循环条件**：`left <= right` 确保当 `left == right` 时仍会检查
- **中点计算**：使用 `(left + right) >> 1` 代替 `/ 2` 以避免溢出
- **边界调整**：找到目标值后直接返回，未找到时调整边界继续搜索

## 时间复杂度与空间复杂度

- 时间复杂度：O(log n)，每次循环将搜索范围减半
- 空间复杂度：O(1)，使用常数级别的额外空间

## 易错点

- 中点计算时可能发生整数溢出（使用 `(right - left) / 2 + left` 可避免）
- 循环条件容易写成 `left < right` 导致最后一个元素未检查
- 边界调整时容易漏掉 `-1` 或 `+1` 操作，导致死循环或范围错误

## 复盘或优化思路

该实现是二分查找的标准模板，已具备较高效率。若需要优化可考虑：
- 进一步优化边界条件处理
- 添加对各种边界情况的详细注释
- 考虑与其他搜索算法（如插值搜索）的性能比较
